# VOLT//R — Electric, Reimagined ⚡

A modern, premium electric motorcycle concept website built with HTML, CSS, and JavaScript.

## 🚀 About the Project

VOLT//R is a responsive electric motorcycle landing page featuring a bold dark theme, neon-lime accents, and modern animations. The project showcases a futuristic electric motorcycle brand concept.

## ✨ Features

* Modern dark UI with neon-lime accents
* Responsive design for mobile, tablet, and desktop
* Animated loading screen
* Interactive motorcycle image slider
* Light and dark mode toggle
* Smooth scrolling and animations
* Contact form with frontend validation

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 💻 Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/muhammadhussain786mughal-debug/website.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.
